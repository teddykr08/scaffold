## 🚀 Next Steps (3 Simple Steps = 5 Minutes)

### Step 1: Create Two Scaffold Apps
Go to your Scaffold dashboard and create:

**App 1: "Builder Help"**
- Name: Builder Help
- Task: explain_term
- Copy the app ID

**App 2: "Template Improver"**
- Name: Template Improver
- Task: improve_template
- Copy the app ID

(Full instructions with templates in QUICK_START.md)

### Step 2: Add Environment Variables
```bash
# Add to .env.local:
NEXT_PUBLIC_HELP_APP_ID=your_builder_help_app_id
NEXT_PUBLIC_IMPROVER_APP_ID=your_improver_app_id
```

### Step 3: Restart Dev Server
```bash
npm run dev
```

**That's it! You're done.** 🎉
